## Quick start

```bash
cd lms
npm install
npm run dev
```

Useful scripts: `npm run test:run`, `npm run audit:source`,
`npm run audit:contract`, `npm run build:release`, and
`npm run deploy:verify -- <dev-url> <prod-url>`.
